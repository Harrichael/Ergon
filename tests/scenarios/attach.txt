# attach records a session ergon didn't start, so ergon work resumes it.

$ cd proj
$ ergon init demo "Build a demo" --no-launch
Created project demo in $ROOT/proj
$ ergon add Backend
qxpj
$ CLAUDE_CODE_SESSION_ID=0b5e0b5e-0000-4000-8000-000000000001 ergon attach root
attached session 0b5e0b5e-0000-4000-8000-000000000001 to demo/root; `ergon prompt demo/root` prints its instructions
$ ergon show root
...
session:   0b5e0b5e-0000-4000-8000-000000000001 in $ROOT/proj
...
$ ergon work root
[claude in $ROOT/proj]
--resume
0b5e0b5e-0000-4000-8000-000000000001

# A task with another session keeps it.
$ ergon attach qxpj --session 0b5e0b5e-0000-4000-8000-000000000002
attached session 0b5e0b5e-0000-4000-8000-000000000002 to demo/qxpj; `ergon prompt demo/qxpj` prints its instructions
$ ergon attach qxpj --session 0b5e0b5e-0000-4000-8000-000000000003
error: demo/qxpj already has session 0b5e0b5e-0000-4000-8000-000000000002; `ergon work demo/qxpj` resumes it
[exit 1]
