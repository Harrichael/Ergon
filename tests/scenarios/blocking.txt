# A task blocks the open work that waits on it or on a task under it,
# directly or through a chain of open work. ergon show names that work and
# its size left; kanban cards carry it beside their own size and attention.

$ ergon init demo Root --no-launch
Created project demo in $ROOT
$ ergon add Schema --size 3 --attention 4
qxpj
$ ergon add API --size 5

$ ergon add Client

$ ergon add Screens --parent nHcx --size 8

$ ergon add Copy --parent nHcx

$ ergon add Billing --size 13
dFR6
$ ergon add Plan --parent dFR6
qwpT
$ ergon add Charge --parent dFR6
AENA
$ ergon add Old
FubR

# API waits on Schema, the Client on the API, and Billing's Charge step on
# the Client: Schema holds all of it back. As in gantt, a step counts its
# share of its sized task, and Copy has no size, so the total is a floor.
