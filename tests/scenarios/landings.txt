# ergon show lists the choros landing sets that carry a task, and --pr finds
# the tasks a PR carries. A set carries the tasks its labels name; a set
# with no labels carries the tasks whose session it was forked from. So one
# session that took on several tasks can land each in its own set.

$ cd ws
$ ergon init demo "Build a demo" --no-launch
Created project demo in $ROOT/ws
$ ergon add Backend

$ ergon add API --parent qxpj

$ ergon add Docs --parent qxpj

$ ergon add Frontend
