## Ergon

These are ergon tasks; change them with the `ergon` CLI (`ergon help` lists
its commands, `ergon tree` shows each task's reference). As the work goes:

- `choros land` from this workspace sets these tasks' statuses; don't set
  them to landing yourself.
- `ergon work` resumes this session only from the folder it began in, so
  don't move that folder, and archive it only with `choros land archive`.

## Choros

This session's folder is in a choros space. `choros here` says:

```
here: workspace backend_the_api_and
```

`choros help agent` says how to work in it. This workspace is bound to
this task: each `choros land` from it tells ergon what it lands.

- `choros land continue` lands a piece. The workspace stays and the task
  stays in_progress. Name a subtask the piece finishes with `--label`, by
  its reference as `ergon tree` shows it, and it is set to landing, unless
  work under it is still open.
- `choros land archive` lands the last of the work: the task is set to
  landing and the workspace is archived. It is refused while a subtask is
  still todo or in_progress. `ergon work` then opens the set's landing
  folder, where review fixes go.

Don't run `choros archive` on this workspace.

These are ergon tasks; change them with the `ergon` CLI (`ergon help` lists
its commands, `ergon tree` shows each task's reference). As the work goes:

- Once all of a task's work is landed or in PRs, set it to landing:
  `ergon edit REF --status landing`.
- Until then, leave it in_progress, and set each subtask whose work is all
  landed or in PRs to landing.
- Name the task references (like demo/nHcx) in each PR's title or body.
- `ergon work` resumes this session only from the folder it began in, so
  don't move or archive that folder.

```
here: workspace space
```

`choros help agent` says how to work in it. Pass each task a land carries to
`choros land` as `--label`, by its reference (like
`--label demo/nHcx`): `ergon show` finds a land's tasks by these
labels. If this session began in a choros workspace, don't run
`choros land archive` or `choros archive` on it.
