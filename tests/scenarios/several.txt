# show, edit and dep take several tasks as `slug,slug`; an edit or a dep is
# made for all of them or none. `edit --append` adds a paragraph to an
# intent, and `-` reads the text from stdin.

$ cd ws
$ ergon init demo "Build a demo" --no-launch
Created project demo in $ROOT/ws
$ ergon add Backend
qxpj
$ ergon add Frontend
FTFE
$ ergon add Docs
nHcx
$ ergon edit qxpj,FTFE --priority p1 --append "Decided: no ORM."
$ ergon show qxpj,FTFE --intent

Decided: no ORM.

demo/FTFE
Frontend

Decided: no ORM.
$ ergon edit nHcx --append - <<EOF

Record that a task depends on another

Each side can be several, as `slug,slug,...`: every task then depends on every one named, or none does if one is refused.

Usage: ergon dep add [OPTIONS] <TASKS> <DEPENDS_ON>

Arguments:
  <TASKS>
          

  <DEPENDS_ON>
          

Options:
      --project <PROJECT>
          Project to act on, instead of the one named by the nearest .ergon file
